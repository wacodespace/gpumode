PTX 的定位

PTX 的真正用途

PTX 是源码意图变为可审查的执行结构的桥梁。

PTX 是虚拟 ISA 和可移植性边界

PTX 不是最终的指令流。它是 NVIDIA 版本化的虚拟 ISA 和编译器目标：足够可读以便审查，足够抽象以跨架构存活，又足够具体以暴露 lowering 结构。

// PTX 命名意图和内存空间
ld.global.v4.u32 [%r8,%r9,%r10,%r11], [%rd4];
mma.sync.aligned.m16n8k16 ...
st.local.u64 [%rd12], %rd88;
编译器目标

前端与 NVIDIA 后端之间的契约

CUDA、Triton、模板库和各种 DSL 都可以先汇聚到 PTX，再由 ptxas 做目标架构特定的 lowering。

审查层

机器码之前的可读结构

寄存器、地址空间、向量宽度、tensor 指令、barrier 和 local memory 流量，在 PTX 层审查比在原始 SASS 中容易得多。

不是最终裁决

PTX 提出度量问题，而非给出答案

PTX 可以暴露溢出路径或标量化访问，但它无法证明运行时开销 — 没有 profiling 和 benchmark，PTX 只是线索，不是结论。
