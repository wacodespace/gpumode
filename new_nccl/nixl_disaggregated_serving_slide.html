内容总结

  • 分离式推理服务（Disaggregated Serving）将 LLM 推理的两个阶段——Prefill（预填充）和 Decode（解码）——拆分到不同的 GPU worker 上独立运行，并通过 NIXL 库实现 KV Cache 的高效传输。
  • 两个阶段的本质差异：
    • Prefill Worker（计算密集型） — 并行处理整个输入 prompt，生成第一个 token 并填充 KV Cache。此阶段大量矩阵乘法，GPU 算力是瓶颈。
    • Decode Worker（内存密集型） — 接收 KV Cache 后逐 token 自回归生成。此阶段每步只生成一个 token，主要瓶颈在于从显存读取 KV Cache 的带宽。
  • KV Cache 传输：Prefill 完成后产生的 KV Cache（每个请求可达数 GB）通过 NIXL 库从 Prefill GPU 直接传输到 Decode GPU。NIXL 支持 GPU↔GPU 直接传输（GPUDirect RDMA）、UCX、NVLink 等多种传输方式，避免经过主机内存中转。
  • Decode 端复用 KV Cache，无需重新计算——这是分离式架构的关键收益：Prefill 的计算结果不会被浪费。
  • 三大核心优势：
    • 更高 GPU 利用率 — Prefill 用计算型 GPU 配置，Decode 用带宽型配置，各取所长。
    • 降低 TCO（总拥有成本） — Prefill 和 Decode 可以独立扩缩容：流量高峰时只需扩 Prefill，长对话多时只需扩 Decode。
    • 更低 TTFT（首 token 延迟） — Prefill 不再阻塞正在进行的 Decode 任务，两者完全解耦并行。
