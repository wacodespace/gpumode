NCCL Feature Release Timeline

NCCL 2.28 to 2.30 feature advances

2.28.3

Device API lands

Device-side NCCL, symmetric kernels, new host collectives, and CE collectives.

2.28.7

GIN starts

GPU-Initiated Networking, ncclCommRevoke, RAS JSON, faster bootstrap.

2.29.2

Elastic jobs

ncclCommGrow, NCCL4Py, LLVM IR, one-sided host APIs, AllGatherV scaling.

2.29.7

Offload + failover

Suspend/resume memory offload, port failover, GIN multi-context, CMake install.

2.30.3

Memory and recovery

Elastic Buffers, TMA, DDP, port recovery, GIN get/timeouts, parameter APIs.

Device API:

  1. Device API provide flexible, high performance HW(GPU/NVLink/RDMA) abstraction
  2. NCCLEP/XFER/UBX/DeepEPv2/customized kernels built on device API
  3. NCCL DSL with cuTe

Host API:

  1. Collective in 3 flavors: default, low latency, zero-sm
  2. CopyEngine, TMA, One side API
  3. Fault tolerance & resiliency & RAS, profiler

中文总结

这页 slide 按版本线梳理了 NCCL 2.28.3 到 2.30.3 的能力演进：2.28 系列引入 Device API、设备侧 NCCL、对称 kernel、GIN、RAS 与更快 bootstrap；2.29 系列推进弹性任务、NCCL4Py、LLVM IR、一侧 Host API、AllGatherV 扩展、内存 offload 与端口 failover；2.30.3 进一步强化 Elastic Buffers、TMA、DDP、端口恢复、GIN 超时/查询和参数 API。底部将重点归为两类：Device API 面向高性能硬件抽象与自定义 kernel/DSL，Host API 面向 collective 变体、CopyEngine/TMA/One-side API 以及容错、RAS 和 profiler。
