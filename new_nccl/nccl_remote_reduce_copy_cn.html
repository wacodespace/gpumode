中文总结

这页说明 NCCL Device API 提供了可在自定义 CUDA kernel 内调用的远程规约与拷贝原语。左侧是多个源地址或窗口，右侧是目标地址或多内存区域；中间三个 API 分别覆盖 N 到 1 的规约求和、1 到 N 的拷贝，以及 N 到 N 的规约后拷贝。它强调这些原语运行在设备端代码中，可用于 LSA 和 multimem 场景，适合开发者组合自定义 collective，但需要注意它不是按 rank 语义封装的 collective，需要同步远端内存，不做重叠检查，并要求 16 字节对齐。
