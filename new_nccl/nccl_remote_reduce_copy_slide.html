中文总结

这页 slide 说明 NCCL Device API 中用于远程 reduce/copy 的底层构建块。它们只能在 device code 的自定义 CUDA kernel 内使用，基于 LSA / multimem，可以把 sources 映射到 destinations 来组合自己的 collective。核心 API 包括 N 到 1 的 ncclLsaReduceSum、1 到 N 的 ncclLsaCopy，以及 N 到 N 的 ncclLsaReduceSumCopy。使用时需要注意：它不是 rank-collective，需要同步远程内存，不做 overlap 检查，并要求 16-byte alignment。
